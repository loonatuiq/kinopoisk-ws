# Инструкции для ИИ-ассистентов (ChatGPT, Codex и др.)

Проект: PWA-поиск фильмов Kinopoisk WS. Один проект Cloudflare Workers: статический сайт из `public/` и API-прокси в `src/worker.js`. Отвечай пользователю по-русски.

## Структура
- `public/index.html`: разметка. `public/styles.css`: стили. `public/app.js`: вся клиентская логика. `public/sw.js`: service worker. `public/manifest.webmanifest`: манифест PWA.
- `src/worker.js`: маршрут `/api/search` (прокси к `https://api.poiskkino.dev/v1.4/movie/search`) и отдача статики через `env.ASSETS`.
- `wrangler.jsonc`: конфигурация. Поле `name` не менять: оно совпадает с именем проекта в Cloudflare.

## Правила
1. **Никаких ключей в коде и коммитах.** API-ключ живёт только в секрете `API_KEY` в Cloudflare (локально в `.dev.vars`, он в `.gitignore`). Клиент ходит только на `/api/search`.
2. Без сборщиков, npm-зависимостей и фреймворков: чистый HTML, CSS и JS. Не добавляй `package.json` без острой необходимости.
3. Данные из API проходят через `normalize()` в `app.js`. Любое поле из API может отсутствовать или быть `null`: проверяй.
4. Состояние поиска (`state`) и избранное (`favorites`) хранятся раздельно. Не смешивай их.
5. Запросы поиска отменяются через `AbortController`: не убирай проверки `controller !== state.controller`.
6. Избранное лежит в `localStorage` (ключ `kinopoisk-ws-favorites`); все обращения идут через объект `storage` с `try/catch`.
7. Service worker не кэширует `/api/*` и чужие домены. Если добавляешь новый файл в `public/`, добавь его в `APP_SHELL` в `sw.js` и подними `VERSION`.
8. Интерфейс: тёмная тема, моноширинный шрифт, крупные зоны нажатия (≥44px), поле ввода 16px (иначе iOS увеличивает страницу), учёт `safe-area`, доступность (подписи, роли, видимый фокус).
9. Тексты интерфейса на русском, ошибки объясняют, что делать дальше.

## Перед коммитом
- Файлы, которые ты меняешь, не должны содержать синтаксических ошибок (`node --check` для `.js`).
- Поиск: обычный запрос, пустой запрос, «ничего не найдено», ошибка сети, «Показать ещё».
- Избранное: добавить, удалить, переключение вкладок, перезагрузка страницы.
- Конвертер: ссылка с `/film/<id>/`, ссылка с лишними параметрами, чужой домен.

Деплой автоматический: коммит в `main` → Cloudflare Workers Builds → публикация.
